# Rules for Image Processing

1. Whenever I am asked to process images, I will look for them in the `temp-image` directory.
2. After processing, I will move the images to the appropriate destination directory (e.g., `src/assets/events/`, `src/assets/past-events/`) based on the user's prompt.
3. I will create/update the UI components (cards) to include these images, following the existing styling and theme of the application.
